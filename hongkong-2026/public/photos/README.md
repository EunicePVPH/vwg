# Header photos

Drop real photographs here named by key: airport.jpg, peak.jpg, oceanpark.jpg, wheel.jpg,
science.jpg, disney.jpg, harbour.jpg, hotel.jpg (about 1200 px wide, JPG).

Only use photos you took, or photos whose license allows it (for example Creative Commons
images on Wikimedia Commons, or the attraction's own press images). Then credit each one in
credits.json so the app can show the credit on the photo:

{
  "peak": { "author": "Photographer name", "license": "CC BY-SA 4.0", "source": "https://commons.wikimedia.org/wiki/File:...", "title": "File title" }
}

You can also set your own photo for any header inside the app: More → Settings & Backup → Header photos.
Until a real photo exists, the app shows a simple illustrated placeholder — never a fake "photo".
