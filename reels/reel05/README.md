# ProVirtual PH — Reel #5: Social Media Strategy, Research & Analysis

Final video: `../../ProVirtual_PH_Reel_05_Social_Media_Strategy.mp4`
(1080x1920, 9:16, 30 fps, 25.0 s, H.264 + AAC stereo, about -14.7 LUFS)

## How it was made
- `reel.html` – all motion graphics, driven by a single `setT(seconds)` function (frame-accurate).
- `render.js` – renders frames with headless Chromium (Playwright).
- `make_audio.py` – original synthesized music + sound effects (numpy only, no samples).
- `sheet.py` – contact-sheet helper used for review.
- Encoded with ffmpeg (libx264, crf 16).
